# 🌸 AniLearn — Modern Japanese Learning Platform (日本語)

An all-in-one, modern, interactive web application to master the Japanese language and JLPT (N5–N1) with real-world anime dialogues, comprehensive Kanji and vocabulary databases, smart grammar drills, and dynamic progress tracking.

Built with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS**. Designed for high performance and offline-ready serverless deployment on **Vercel**.

---

## ✨ Features

- **🗾 Comprehensive Kana Syllabary**: Interactive charts for Hiragana and Katakana with Romaji and stroke guides.
- **🏮 Kanji Master Dictionary**: Over 318 JLPT N5–N4 Kanji with Onyomi, Kunyomi, stroke counts, meanings, and compound examples.
- **📚 1,488+ JLPT Vocabulary**: Filter by JLPT level (N5, N4, etc.), part of speech, and search in English, Kanji, or Romaji.
- **📖 215+ Grammar Library**: Detailed grammar formulas, contextual usage rules, and real-life sentence examples.
- **🎬 Anime Scenarios & Dialogues**: Immersive dialogue cards based on popular anime scenes to learn natural conversational phrasing.
- **📝 JLPT Mock Exams & Quizzes**: Timed JLPT simulation exams and quick-fire practice drills with instant scoring and explanations.
- **🌸 Nikki's Japanese Classroom**: Guided study days (Classes 404 to 464) and interactive homework categories.
- **⚡ Daily Sentence Batches**: 3,000 contextual Japanese study sentences distributed across daily schedules.
- **🏆 Dynamic Leaderboards & Streaks**: Earn XP for every completed drill, maintain your daily study streak, and climb the ranks.
- **🚀 100% Serverless & Client-Side**: Powered by client-side caching and localStorage state persistence with zero server latency.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aneeshunique007/japanese-website.git
   cd japanese-website/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Run test suite:
   ```bash
   npm test
   ```

---

## 🌐 Deployment

This application is deployed on **Vercel**. The frontend can be served as a single-page application with automatic rewrites.
